## About This Website

This is my personal academic portfolio website, showcasing my research in chemistry, materials science, and engineering. The site was built using the excellent [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme by [Maruan Al-Shedivat](https://alshedivat.github.io/).

### Features

- **Academic Portfolio**: Showcases research projects, publications, and professional experience
- **Project Gallery**: Interactive displays of research work including 3D printing, ALD precursors, and thesis projects
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile devices
- **Dark Mode Support**: Automatic theme switching based on system preferences
- **Fast & SEO-Friendly**: Optimized for performance and search engines

### Technologies Used

- **Jekyll**: Static site generator
- **GitHub Pages**: Free hosting and deployment
- **SCSS/Sass**: Custom styling and theming
- **Bootstrap**: Responsive layout framework
- **JavaScript**: Interactive elements and functionality

## Getting Started

To run this website locally:

1. Clone this repository
2. Install Jekyll and dependencies
3. Run `bundle exec jekyll serve`
4. Visit `http://localhost:4000`
